# Сайт-портфолио «Ольга Косых»

Одностраничный сайт на чистом HTML / CSS / JS для малого бизнеса:
лендинги, сайты-визитки и автоматизация заявок. Без сборщиков, фреймворков и админки.

- **Боевой сайт:** https://kosyhafrilanser.online/ (хостинг reg.ru).
- **Техническое превью:** https://lazyness680-gif.github.io/portfolio/ (GitHub Pages; Яндекс Форма работает, `.htaccess` — нет).

## Локальный просмотр

Из папки `portfolio/`:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`.

Заявки принимает встроенная Яндекс Форма: для неё PHP не нужен, достаточно статического сервера и доступа в интернет. Если форма не отрисовалась — проверьте, что браузер не блокирует `forms.yandex.ru` и что в консоли нет ошибок CSP.

## Что заменить перед публикацией

### 1. Фото

В hero-блоке стоит портрет `assets/img/olga.jpg` (635×686, ~65 КБ). Если захотите заменить — положите новый портрет в `assets/img/` и обновите путь и размеры в `index.html`:

```html
<img src="assets/img/olga.jpg" alt="Ольга Косых" width="635" height="686" fetchpriority="high">
```

Кадр лучше вертикальный, от 800 px по ширине, JPEG/WebP до 200 КБ. Пропорции рамки заданы в `css/styles.css` (`.photo-frame`, `aspect-ratio`) — подгоните под новое фото, чтобы не обрезать лицо. После замены фото пересоберите `og-image.jpg` (1200×630), чтобы превью в соцсетях совпадало.

### 2. Контакты

Поиском по проекту замените:

- `@Aleka_Olga` — если изменится Telegram;
- `kosyha@list.ru` — если изменится почта;
- `https://github.com/lazyness680-gif` — профиль GitHub.

### 3. Домен

Боевой домен уже прописан: **https://kosyhafrilanser.online/**. Если он изменится, замените адрес в:

- `index.html` — `canonical`, Open Graph, Twitter Card, JSON-LD;
- `privacy.html` — `canonical` и текст политики;
- `sitemap.xml`;
- `robots.txt`.

### 3.1. DNS и IP на reg.ru

Домен `kosyhafrilanser.online` указывает на хостинг reg.ru. В панели домена должны быть записи:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | `@` | `31.31.196.39` |
| AAAA | `@` | `2a00:f940:2:2:1:1:0:34` |
| A | `www` | `31.31.196.39` |
| AAAA | `www` | `2a00:f940:2:2:1:1:0:34` |

Если панель reg.ru сама подставляет A-записи хостинга — сверьте, что IPv4 и IPv6 совпадают с указанными. После смены DNS подождите 1–24 часа (обычно 1–2 часа).

### 4. Тексты, кейсы, цены

Всё в `index.html`, секции подписаны комментариями:

- `<!-- PAINS -->` — боли;
- `<!-- SERVICES -->` — услуги;
- `<!-- CASES -->` — кейсы: лендинг для бренда шоколада (реальный, живой сайт [niperom.ru](https://www.niperom.ru/), код [niperom-landing](https://github.com/lazyness680-gif/niperom-landing)), сайт для психолога ([psyhonline-site](https://github.com/lazyness680-gif/psyhonline-site), реальный), магазин «Инструменты» (в работе), ИИ-администратор ВК ([vk-ai-admin-bot](https://github.com/lazyness680-gif/vk-ai-admin-bot), демо), TimeTracker ([TimeTracker](https://github.com/lazyness680-gif/TimeTracker), демо); формат «Было → Сделали → Стало»;
- `<!-- PRICING -->` — пакеты и цены;
- `<!-- FAQ -->` — вопросы и ответы.

Цены пакетов «Сайт + заявки под ключ» и «Автоматизация» пока «по запросу» — впишите, когда определитесь.

### 5. Яндекс.Метрика

1. Создайте счётчик в [Метрике](https://metrika.yandex.ru/).
2. В `index.html` найдите закомментированный блок `Яндекс.Метрика`, замените `XXXXXXXX` на номер счётчика и раскомментируйте.
3. В `js/main.js` в начале файла укажите:

```js
var METRIKA_ID = 12345678; // номер счётчика
```

Цели, которые отправляются автоматически: `lead_submit`, `tg_click`, `quiz_complete`, `quiz_tg_click`, `case_open`, `email_click`. Создайте их в Метрике с такими же идентификаторами.

## Форма заявок — Яндекс Форма

Заявки принимает встроенная [Яндекс Форма](https://forms.yandex.ru/u/6af609a828697b9c935d7c91/). Код вставлен в `index.html` в секции `<!-- CONTACT -->` целиком, вместе с `embed.js`:

```html
<script src="https://forms.yandex.ru/_static/embed.js"></script>
<iframe src="https://forms.yandex.ru/u/6af609a828697b9c935d7c91?iframe=1" frameborder="0" name="ya-form-6af609a828697b9c935d7c91" width="650"></iframe>
```

`embed.js` сам подгоняет высоту iframe под содержимое через `postMessage`. Ширину задаёт CSS-класс `.ya-form-full` (`width: 100% !important`), поэтому форма занимает всю ширину контейнера, в том числе на телефоне.

### Настройки формы

1. Откройте форму в [конструкторе Яндекс Форм](https://forms.yandex.ru/admin/).
2. Вопросы, обязательность и текст кнопки меняются там же — правки в коде сайта не нужны.
3. Уведомления о новых ответах: **Настройки → Уведомления** — включите письмо на `kosyha@list.ru` (или другой адрес).
4. Ответы хранятся в личном кабинете Яндекс Форм: **Форма → Ответы**, выгрузка в Excel/CSV.

### Что важно при замене формы

- Вставляйте код новой формы целиком, вместе со строкой `<script src="https://forms.yandex.ru/_static/embed.js"></script>` — без неё iframe не будет менять высоту.
- Если меняется домен формы, обновите его в `index.html` и в CSP-заголовке `.htaccess` (`script-src`, `connect-src`, `frame-src` — `https://forms.yandex.ru`).
- Старые файлы `api/lead.php` и `api/config.php` остаются на хостинге как legacy и формой не используются. Их можно удалить, если не нужны.

> Google Таблицы и скрипт `Code.js` в проекте не используются.

## Деплой на reg.ru

Боевой сайт: **https://kosyhafrilanser.online/**

| Параметр | Значение |
| --- | --- |
| Домен | `kosyhafrilanser.online` |
| IPv4 | `31.31.196.39` |
| IPv6 | `2a00:f940:2:2:1:1:0:34` |
| Корень сайта | `www/kosyhafrilanser.online/` (в панели ISPmanager; встречается и `public_html/`) |
| PHP | не требуется для формы (Яндекс Форма), но хостинг поддерживает 8.0+ |

1. **Домен.** Убедитесь, что домен `kosyhafrilanser.online` привязан к хостингу reg.ru.
2. **DNS.** Проверьте A/AAAA-записи по таблице из раздела «3.1. DNS и IP на reg.ru».
3. **SSL.** Включите бесплатный SSL Let's Encrypt в панели, дождитесь выпуска и включите редирект на HTTPS.
4. **Загрузка файлов.** Через FTP/SFTP (FileZilla) загрузите **содержимое** папки `portfolio/` в `public_html/` — так, чтобы `index.html` лежал прямо в корне.
5. **Права.** Файлы — `644`, папки — `755`. Файл `.htaccess` загружайте в бинарном режиме.
6. **Форма.** Ничего настраивать на хостинге не нужно: форма встроена из Яндекс Форм. Проверьте только, что в `.htaccess` загружен обновлённый CSP с `https://forms.yandex.ru`.
7. **Проверка.** Откройте `https://kosyhafrilanser.online/`, проверьте:
   - тему (светлая/тёмная);
   - меню на телефоне;
   - квиз;
   - раскрытие кейсов и FAQ;
   - загрузку Яндекс Формы и отправку тестового ответа;
   - ширину формы на телефоне (должна быть во всю ширину экрана);
   - `https://kosyhafrilanser.online/404.html` и несуществующий адрес;
   - `robots.txt` и `sitemap.xml`.
8. **Вебмастер.** Добавьте сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru/), подтвердите домен, отправьте `sitemap.xml`.

### Если хостинг без PHP

Форма работает и без PHP — она встроена из Яндекс Форм. Достаточно статического хостинга с HTTPS. Учтите только, что `.htaccess` (CSP, редиректы, 404) действует лишь на Apache: на GitHub Pages его нет, а CSP-заголовки там не выставляются.

## Технические заметки

- Сайт полностью статический, правки — в коде. Админки нет by design.
- Тёмная тема хранится в `localStorage`, по умолчанию — системная.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
- CSS-переменные тем — в начале `css/styles.css`.
- Кейсы и FAQ — нативные `<details>`, работают без JS.
- Квиз требует JS; форма — встроенный iframe Яндекс Форм и работает независимо от скриптов сайта.
- Шрифты — Google Fonts (Lora + Manrope). Можно заменить на локальные, чтобы убрать внешнюю зависимость.
